# Winter Fair 2026 · Foyer Group

Page de partage LinkedIn de **Winter Fair 2026 · Foyer Group** : https://foyer-groupe.github.io/winter-fair/

La personne scanne le QR code de l'affiche, la page s'ouvre dans la langue de son téléphone (français ou anglais),
et le bouton « Partager sur LinkedIn » ouvre un post déjà rédigé. Il ne reste qu'à ajouter une photo et publier.

**Ne pas modifier ce dépôt à la main** : il est regénéré à chaque publication par l'outil interne de Foyer Group
`foyer-smart-qr-code-creator`. Pour changer le texte ou le visuel, passer par l'outil puis republier.
L'adresse de la page ne change jamais : elle est imprimée dans le QR code.
